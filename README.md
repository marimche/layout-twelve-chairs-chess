Адаптивный лендинг для шахматного клуба. Создан в рамках тестового задания.

[Посмотреть готовый проект](https://marimche.github.io/layout-twelve-chairs-chess/)

### 🛠 Технологии
* **HTML5** / **CSS3**
* **БЭМ**
* **JavaScript** (для слайдера)
* **Адаптивная верстка** (desktop-first, от $1366\text{px}$ до $375\text{px}$)

### ✨ Особенности верстки
* **Кроссбраузерность:** корректное отображение во всех современных браузерах.
* **Интерактивность:** плавная анимация.
* **Кастомный слайдер:** написан вручную, без использования тяжелых библиотек.
